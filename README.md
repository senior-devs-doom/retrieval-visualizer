# Wizualizator wyszukiwania i kontroli jakości

Okrojony WIP pracy inżynierskiej (klasyczne ML: ASIFT + Shape Context + Opponent Color, kodowanie VLAD, indeks HNSW). Statyczna strona; otwórz `index.html` lub stronę GitHub Pages tego repozytorium.

Zakładki: **Bryły 3D** (renderowane instrumenty, wyniki wobec kąta widzenia) i **Kontrola jakości** (MVTec AD, wynik anomalii, najbliższe dobre zdjęcie, maska wady).
