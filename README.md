# Wizualizator wyników: wyszukiwanie tych samych obiektów (GSO)

Strona statyczna do pracy inżynierskiej *Wyszukiwanie tych samych obiektów w zbiorach obrazów z wykorzystaniem klasycznych i głębokich reprezentacji cech* (Karol Chruzik, AGH). Pokazuje zapytania, najbliższych sąsiadów, mapę t-SNE, tryb różnic i decyzję znany/nieznany z kolorowym tokenem pewności.

Strona: <https://senior-devs-doom.github.io/retrieval-visualizer/>
Kod modelu i generatora strony: <https://github.com/senior-devs-doom/wyszukiwanie-tych-samych-obiektow-w-zbiorach-obrazow> (`scripts/visualizer.py`).
